# 🏀 Features

## 🔧 Modifications

- **Add Item:** You can add items to your To Do list.
- **Edit Item:** You can edit information about your items.
- **Delete Item:** You can delete items if you no longer need them.
- **Check Item:** You can check items by striking through them.

## ⚙️ Options
- **Sort Items:** You can sort items from a list.
- **Filter Items:** You can filter items from a list.
- **Clear Checked Items:** You can remove items that are checked from the list.
- **Clear Filters:** You can remove all filters.
- **Clear Options:** You can reset sorting and filter options.

# 📥 Download

1. Open terminal.
2. Select a directory and enter the following command to get there: `cd {directory_name}`.
3. Clone the repo by executing: `git clone https://github.com/ivanbaradi/to-do`.

# 🚀 How to Run

1. Open terminal.
2. Command **cd** to the repository where the repo was cloned at.
3. Run application by executing `npm start`.

## 💻 Visual Studio Code

If you have Visual Studio Code:

1. Under **File**, click **Open** to open this project.
2. Under **Terminal**, click **New Terminal** to open a new terminal.
3. Execute the same command line from above to run the application.

Keep in mind that when you open a new terminal in VS Code, it directs you to this project's directory. In other words, you don't need to execute multiple command lines to get to this project's directory.
